# Analogital Pocket

写真を1枚選び、ワンタッチで暖色フィルム風の色に変えて、**新しいファイル**として保存する小さなPWAです。

- 写真は端末の外に送りません（すべてブラウザ内で処理）。
- 元の写真は変更しません（非破壊。必ず別ファイルで保存）。
- Android Chrome 向け。ホーム画面の「📲 ホーム画面に追加」ボタン（または ⋮ メニュー）でアプリのように使えます（PCブラウザでも動きます）。
- 家族・友人にリンクを共有して使う想定（検索エンジンには出さない設定＝noindex を付与）。

## 使い方
1. 「写真を選ぶ」でJPEGを1枚選ぶ
2. レシピ（Jostalgic／MESHITERO／JOCROS R）を選んで色を変える
3. 「保存する」で変換後を新しいファイルとして保存

## 開発メモ
- 依存ライブラリなし（HTML / CSS / JavaScript のみ）。追加費用ゼロ。
- 画像処理は Canvas（ブラウザ標準）。色変換は事前計算した対応表（LUT）で高速化。
- 写真の向きは EXIF を反映（`createImageBitmap` の `imageOrientation`）。保存時に位置情報などの撮影メタデータは引き継がれません。
- アイコンは `node tools/make-icons.js` で再生成できます（開発時のみ。アプリには同梱の PNG を使用）。

レシピ3種類（Jostalgic／MESHITERO／JOCROS R）。色はユーザーの調整前後のペア写真から生成。明るさ・グレイン調整、トリミング（自由＋比率固定 1:1/4:5/16:9・縦横入替・傾き補正）に対応。
